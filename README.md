# Cardápio Digital ONE PIECE

Projeto inicial de cardápio digital para a Adega e Lanchonete One Piece.

## Arquivos
- `index.html`: estrutura da página.
- `style.css`: cores e aparência.
- `script.js`: categorias, produtos e preços.

## Como abrir no VS Code (Linux)
1. Extraia o arquivo ZIP.
2. Abra o VS Code.
3. Clique em **Arquivo > Abrir Pasta**.
4. Escolha a pasta `one_piece_cardapio`.
5. Abra o arquivo `index.html`.
6. Clique com o botão direito e escolha **Open with Live Server**, se a extensão Live Server estiver instalada. Também pode abrir o `index.html` diretamente no Firefox.

## Categorias
- Bebidas: cervejas, refrigerantes e água.
- Lanches: batatas fritas, pastéis, salgados e hot dogs.
- Doces: bolos de pote e pudins.

Confira os preços e descrições antes de publicar para os clientes.

As categorias exibem somente os produtos e preços em listas, sem fotos. Ao clicar em Bebidas, Lanches ou Doces, o conteúdo muda na mesma página.
